## About The Project

Kazira.io is a revolutionary platform designed to bridge the gap between current capabilities and future demands. We leverage cutting-edge AI to deliver:

-   **Personalized Learning Paths:** Master in-demand skills with AI-curated educational journeys through **Kazira Learn**.
-   **Intelligent Automation Tools:** Streamline workflows and boost productivity with smart automation solutions from **Kazira Automate**.
-   **A Community of Innovators:** Connect, collaborate, and grow with like-minded individuals and experts.

This repository contains the frontend implementation of the Kazira.io web application, designed to run directly in the browser with no build step required.

---

## Key Features

-   **AI-Powered Learning Plan Generation:** Users can input their interests and skill level to receive a personalized, week-by-week learning plan generated by the Google Gemini API.
-   **AI-Grounded Search:** Find real-world resources for learning tasks using Google Search grounding via the Gemini API.
-   **Mock Authentication:** A simulated user login and profile management system.
-   **Responsive Design:** A fully responsive and accessible UI built with TailwindCSS.
-   **Dynamic Content:** Interactive elements and smooth animations powered by Framer Motion.
-   **"Kenya's Final AI Exam":** A thought-provoking section exploring the deep, contextual challenges of AI implementation in Kenya.

## Tech Stack

This project adheres strictly to the following technology stack:

-   **Core Framework:** [React 19](https://react.dev/)
-   **Language:** [TypeScript](https://www.typescriptlang.org/)
-   **Routing:** [React Router DOM](https://reactrouter.com/)
-   **UI/Styling:** [TailwindCSS](https://tailwindcss.com/)
-   **Animations:** [Framer Motion](https://www.framer.com/motion/)
-   **AI SDK:** [Google Gemini API (`@google/genai`)](https://github.com/google/generative-ai-js)
-   **Module System:** ES Modules with [Import Maps](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/script/type/importmap) (zero build step).

## Getting Started

This project is designed to run without a complex build process.

1.  **Prerequisites:**
    -   A modern web browser (e.g., Chrome, Firefox, Safari, Edge).
    -   A local web server to serve the files. You can use the `http-server` npm package or the Live Server extension in VS Code.

2.  **Configuration:**
    -   To use the AI features, you must have a Google Gemini API key. The application is configured to read this key from a `process.env.API_KEY` variable, which should be made available in the execution environment.

3.  **Running the Application:**
    -   Serve the project's root directory using a local web server.
    -   Open your browser and navigate to the local server's address (e.g., `http://localhost:8080`).

## Security Note

-   **API Key Handling:** This application is a prototype and uses a client-side API key (`process.env.API_KEY`) as per its execution environment's constraints. In a production environment, all API calls to services like Google Gemini should be proxied through a secure backend server to protect the API key.
-   **Authentication:** The current authentication system is a mock implementation using `localStorage`. A production application should use a secure, token-based (e.g., JWT) authentication system with a proper backend.
