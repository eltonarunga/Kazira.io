## About The Project

Kazira.io is a revolutionary platform designed to bridge the gap between current capabilities and future demands. We leverage cutting-edge AI to deliver:

-   **Kazira Automate (Flagship Product):** Featuring *Kazira.io Clinical Intelligence*, an advanced AI-powered platform for clinical data analysis designed to streamline healthcare decision-making through synthesized insights.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or higher recommended)
-   npm or yarn

### Installation & Setup

1.  **Clone the repository** (or download the source code).
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Environment Variables:**
    To use the AI features (like the Chatbot and Learning Plan generator), you must have a Google Gemini API key. Ensure `process.env.GEMINI_API_KEY` or the relevant environment variable is configured in your deployment/development environment.
4.  **Run the development server:**
    ```bash
    npm run dev
    ```
5.  **Build for production:**
    ```bash
    npm run build
    ```

## Security & Legal

### Terms of Service & Privacy Policy
Kazira.io enforces strict Terms of Service and Privacy Policies. **Unauthorized scraping, vulnerability testing, reverse engineering, or security circumvention is strictly prohibited** and will result in immediate termination of access and potential legal repercussions.

### Prototype Security Note
This frontend repository contains intentional simplifications for demonstration purposes. 
- **API Keys:** In a true production environment, all calls to external AI APIs (like Gemini) must be proxied through a secure backend server to prevent exposing API keys to the client.
- **Authentication:** The current authentication is mocked using local state/storage. A production deployment requires a secure backend (e.g., Firebase Auth, Auth0, or a custom backend with HttpOnly cookies) for session management and authoritative data validation.
